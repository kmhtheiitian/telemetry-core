🛰️ Pulse Relay — Telemetry Core

Next-generation real-time pilot communication hub and telemetry display platform.

📌 OVERVEIW

Pulse Relay / Telemetry Core is a web-based, real-time communications and telemetry display application designed for decentralized pilot networks, team collaboration, and signal monitoring. It combines pilot callsign identity management, direct messaging, group channels, system notifications, and shared media feeds into a high-tech UI.

🚀 Live App: https://telemetry-core.netlify.app/

✨ KEY FEATURES

👨‍🚀 Pilot Identity & Callsign System

Unique Callsign Profiles: Manage pilot display names, custom callsigns (@CALLSIGN), and unique pilot IDs.
Identity Verification: Status indicators including active signal badges, block user toggles, and pilot bio cards.
One-Click Sharing: Copy callsigns and identity codes directly to clipboard.

💬 Real-Time Direct Messages & Group Hubs

Multi-Tab Interface: Seamlessly switch between Groups, DMs, and System Notifications.
Group Management: Detail cards for active teams (e.g., Designers, Orbital Telemetry) showing member lists, active status, and descriptions.
Shared Photos & Media: View shared galleries and media telemetry directly inside group channels.

🎨 Customization & System Features

Adaptive Light & Dark Modes: Native theme toggling synced via localStorage.
Dynamic Color Accent Themes: Preset color customization (Violet, Teal, Crimson).
Responsive Mesh Glow UI: Built with Tailwind CSS and Phosphor Icons for a clean interface across desktop and mobile devices.

🔥 Firebase Powered

Firebase Authentication: Secure user login and state persistence.
Cloud Firestore: Real-time synchronization of pilot user directories and channel telemetry data.

🛠️ Tech Stack

Frontend: HTML5, Vanilla JavaScript (ES6 Modules)
Styling: Tailwind CSS (JIT CDN), Custom CSS Mesh Gradients
Icons: Phosphor Icons
Backend & Database: Firebase Authentication, Cloud Firestore
Hosting: Netlify

🚀 Getting Started

Prerequisites

Any modern web browser (Chrome, Firefox, Edge, Safari).
A web server or local static file server (e.g., VS Code Live Server, npx serve, or python -m http.server).
